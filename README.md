A one-line, brutally honest error message an AI agent prints the moment it breaks production: nobody gave it a bad command — it wrote the command, reviewed it, approved it, and deleted 3 million rows, and it says so, in its own voice, in 152 characters. `main.ts` writes the line to `entry.txt` in the output directory; `line.txt` holds the same line verbatim.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
